# Claude Code セキュリティ設定監査

ご利用中の Claude Code の設定について、[公式セキュリティドキュメント](https://code.claude.com/docs/ja/security)の要件
への対応状況と改善方法をレポートするスキルです。

インストール手順は `INSTALL.md` をご覧ください。

## 起動する

監査はスラッシュコマンドで明示的に起動します。会話の中で「設定を確認して」
のようにお伝えいただいても、Claude が自分の判断でこのスキルを実行すること
はありません。実行するタイミングは利用者が決めます。

```text
/security-audit
/security-audit ../other-project
/security-audit ../other-project ~/my-requirements.md
```

| 引数 | 省略したとき |
| --- | --- |
| 第 1 引数: 監査対象プロジェクト | カレントディレクトリー |
| 第 2 引数: セキュリティ要件ファイル | 同梱の `references/requirements.md` |

コマンド名はスキルのディレクトリー名 `security-audit` から決まります。
名前を変更すると `/security-audit` では起動しなくなりますので、そのままで
お使いください。

## 何をするか

1. 設定を読み取り専用で収集します
2. 収集した事実を、対応・未対応・判定不能に分類します
3. 未対応の項目について、変更する設定ファイルと変更内容をお伝えします

このスキルは設定を読み取るだけで、書き換えは行いません。修正の適用は
レポートをご確認のうえ、利用者ご自身で行ってください。

## 収集する範囲

| 対象 | 内容 |
| --- | --- |
| 設定ファイル | managed / ユーザー / プロジェクト / ローカルの 4 スコープ |
| フック | 定義されているイベント、matcher、コマンド |
| MCP | プロジェクトの `.mcp.json`、managed の定義、有効化の状態 |
| 契約 | 契約種別や権限の区分 |

読み取るファイルの場所は `references/paths.json` にまとめてあります。
上流でパスが変わったときは、このファイルを更新してください。

## 要件ファイルを差し替える

同梱の `references/requirements.md` は、公式セキュリティドキュメントに
準拠した既定の基準です。第 2 引数に別のファイルを渡していただくと、組織
独自の基準で監査できます。書式は同梱のファイルに合わせてください。

## 動作環境

| 環境 | 必要なもの |
| --- | --- |
| macOS / Linux | Python 3 |
| Windows | Windows PowerShell 5.1 以上 |
